# Как сменить DNS-сервер

Адреса популярных сервисов приведены в разделе [Публичные DNS-серверы](/#public-dns).

## Как сменить DNS-сервер в Windows

Чтобы сменить DNS-сервер в Windows:

1. Откройте **Параметры** → **Сеть и Интернет** и выберите подключение — **Ethernet** или **Wi-Fi**.
1. Нажмите **Изменить** рядом с пунктом **Назначение DNS-сервера**.
1. Выберите **Вручную**, включите переключатель **IPv4** и введите адреса _предпочитаемого_ и _альтернативного_ DNS-серверов — например, `8.8.8.8` и `8.8.4.4`.
1. Нажмите **Сохранить**.

## Как сменить DNS-сервер в macOS

Чтобы сменить DNS-сервер в macOS:

1. Откройте **Системные настройки** → **Сеть**.
1. Выберите ваше подключение и нажмите **Подробнее** → **DNS**.
1. Нажмите `+` и добавьте адреса DNS-сервера.
1. Нажмите **ОК**.

## Как сменить DNS-сервер в Linux

В системах с NetworkManager выполните в терминале:

```bash
nmcli connection modify _имя-подключения_ ipv4.dns "8.8.8.8 8.8.4.4" ipv4.ignore-auto-dns yes
nmcli connection up _имя-подключения_
```

Список подключений можно посмотреть командой `nmcli connection show`.

## Как сменить DNS-сервер на роутере

Чтобы сменить DNS-сервер сразу для всех устройств в домашней сети:

1. Откройте веб-интерфейс роутера — обычно по адресу `192.168.0.1` или `192.168.1.1`.
1. В разделе с настройками WAN или DHCP укажите адреса DNS-сервера.

## Как сбросить DNS-кэш после смены сервера

После смены сервера сбросьте локальный DNS-кэш, чтобы устройство сразу начало использовать новый сервер:

- Windows — выполните в командной строке `ipconfig /flushdns`.
- macOS — `sudo dscacheutil -flushcache && sudo killall -HUP mDNSResponder`.
- Linux (systemd) — `sudo resolvectl flush-caches`.

Проверить, какой сервер используется теперь, можно по инструкции [Как узнать, какой DNS-сервер использует ваше устройство](/check-dns).
